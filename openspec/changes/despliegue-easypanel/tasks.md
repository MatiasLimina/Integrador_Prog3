# Tasks

> Gobernanza ALTA. Marcadores: **[agente]** = cambio en el repo que puede hacer el agente; **[grupo]** = paso que ejecuta una persona del grupo (el agente no tiene acceso). Todo lo de Easypanel se hace **desde la interfaz web** (sin SQL ni CLI en el VPS); la única excepción es el retiro del backend del TP (§6), que va por SSH. **⚠ CONFIRMAR** = paso con efectos (credenciales, datos, publicación, bajas) que no se ejecuta sin confirmación explícita del grupo en la conversación. Los nombres de pestañas y botones de Easypanel son orientativos (la interfaz puede variar): lo que importa es el resultado de cada «Verificar». Comandos locales en PowerShell, una línea cada uno, desde la raíz del repo salvo que se indique otra carpeta; comandos de la Console de Easypanel en `sh`. Sin archivos de test ni runners en `frontend/` (regla dura 1); si se toca `backend/`, `pytest` debe seguir pasando. Registrar el resultado real; nunca marcar como hecho lo no ejecutado. Ninguna captura ni archivo versionado puede mostrar `DATABASE_URL`, la «Internal Connection URL», claves ni IP del VPS (regla dura 6).
>
> Datos fijos (decididos por el grupo): proyecto Easypanel `gordos_programacion`; servicios `global_db` (Postgres), `backend` y `frontend`; `API_UPSTREAM=gordos_programacion_backend:8000`; host interno de la base `gordos_programacion_global_db`.
